# 0003. Usar Python 3.14

- Status: aceita
- Data: 2026-11-22
- Requisitos relacionados: RNF09

## Contexto

O projeto precisa de uma versão de Python fixa para que todos os ambientes (desenvolvimento, testes e produção) se comportem da mesma forma. O RNF09 pede controle de versão e documentação técnica atualizada.

O ambiente virtual do projeto (`.venv`) usa Python 3.14.0, com o Django 6.1.3 e as demais dependências do `requirements.txt` instaladas. Segundo as notas de lançamento e o FAQ de instalação da documentação oficial do Django, o Django 6.1 suporta oficialmente Python 3.12, 3.13, 3.14 e (a partir do 6.1.3) 3.15.

## Direcionadores da decisão

- A mesma versão em todos os ambientes.
- Compatibilidade com o Django e com as dependências fixadas.
- Suporte de longo prazo da linguagem durante a vida do projeto.

## Opções consideradas

1. Python 3.14.
2. Uma versão anterior da linha 3.x.

## Decisão

Opção 1. O projeto usa Python 3.14 em todos os ambientes.

## Consequências

- Positivas:
  - Versão recente, oficialmente suportada pelo Django 6.1, com suporte da linguagem por mais tempo.
- Negativas e custos:
  - Algumas bibliotecas podem demorar a oferecer suporte ou pacotes prontos para a versão mais nova. Cada nova dependência precisa ser conferida para o Python 3.14 antes de entrar no `requirements.txt` (ADR 0004).
  - A documentação do Django recomenda e suporta oficialmente a última versão micro (`A.B.C`) de cada série do Python; o ambiente local está em 3.14.0 e deve acompanhar as atualizações de manutenção da série 3.14.
- Impacto em specs e arquitetura:
  - A hospedagem escolhida precisa oferecer Python 3.14.

## Como verificar

- `.venv\Scripts\python --version` mostra 3.14.x.
- A pipeline de testes, quando existir, roda em Python 3.14.
